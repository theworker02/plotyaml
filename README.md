# plotyaml

Plot host/yaml network string helpers for config audits.

**Site:** https://theworker02.github.io/plotyaml/

## Install / run

```bash
git clone https://github.com/theworker02/plotyaml.git
cd plotyaml
node src/cli.js
node --test
```
